# CampusBite Islamabad

Assignment 02 project for CS4032 Web Programming at FAST-NUCES Islamabad.

## Stack

- Vite
- React
- React Router
- Plain CSS

## Setup

```powershell
npm install
npm run dev
```

## Build

```powershell
npm run build
npm run preview
```

## Test

```powershell
npm test
```
