# CampusBite Islamabad

Assignment 02 project for CS4032 Web Programming at FAST-NUCES Islamabad.

## Stack

- Vite
- React
- React Router
- Plain CSS

## Setup

```powershell
npm install
npm run dev
```

## Build

```powershell
npm run build
npm run preview
```

## Test

```powershell
npm test
```

## Assignment report

The submission-ready PDF source and generated report are:

- `report.md`
- `CS4032_Assignment_02_CampusBite_Report.pdf`
- `generate_report_pdf.py`

Regenerate the PDF after updating the report:

```powershell
python generate_report_pdf.py
```
